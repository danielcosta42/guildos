# Phase 0: the name BRutus leaves the addon. Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No trace of the old "BRutus" name is left in the addon. The `BRutus` global alias becomes
`GuildOS` everywhere. `BRutusDB`, the legacy comm prefix and `/brutus` and `/br` go, and the Loot
Master's `BRutusLM` prefix becomes `GuildOSLM`.

**Architecture:** First a guard harness that fails while the name is anywhere in a tracked file. Then
the four removals are made by hand, because each deletes behaviour. Then the rename is one mechanical
substring replacement over every tracked text file. Last, the dev addon outside the repo is updated.

**Tech Stack:** Lua 5.1 (WoW addon), LuaJIT harnesses in `tools/`, luacheck, Python for the one-off
rename script, GitHub Actions release workflow.

**Spec:** `docs/superpowers/specs/2026-10-07-ui-styles-design.md` §3 (epic #119). This phase is issue #120.

## Global Constraints

- **The name.** No `brutus`, in any case, in a tracked file except `CHANGELOG.md`, `Libs/`,
  `docs/superpowers/specs/*`, `docs/superpowers/plans/*` (dated records) and `tools/no-brutus.lua`
  (it has to name what it looks for).
- **Saved variables:** `GuildOSDB` only.
- **Slash commands:** `/guildos` and `/gos` only.
- **Loot Master prefix:** `GuildOSLM` only. The old one is not accepted (decided 2026-10-07: switch at
  once). It is one constant, `LootMaster.PREFIX`, used everywhere.
- **No other behaviour change** beyond these four removals and the prefix.
- **Commit type.** Commits are `refactor:` (the release workflow bumps the patch). Never `feat!:`, and
  never the words "BREAKING CHANGE" in a commit message, which bump the major version.
- **Commit messages.** In Portuguese, with no AI attribution of any kind.
- **Checks before claiming done:** every `tools/*.lua` passes, and luacheck is
  `0 warnings / 0 errors`.

## Review Focus

1. **Global frame names after the rename.** Named frames like `BRutusScanTooltip` become
   `GuildOSScanTooltip`. If a `GuildOS…` frame of the same name already exists, the two collide and
   the later `CreateFrame` silently replaces the first. Pinned in Task 3, step 4.

5. **Another addon reading `_G.BRutus`.** The only known one is the dev addon GuildOS_Demo. Pinned in

- [ ] **Step 1: Write the guard**

```lua
-- No "BRutus" left in the addon (issue #120, spec docs/superpowers/specs/2026-10-07-ui-styles-design.md §3).
--
-- The addon was called BRutus before it was Guild OS, and the name lived on as a global alias, a saved
-- variable, a comm prefix and two slash commands. All of it is gone; this fails if any of it comes back
-- in a file git tracks. CHANGELOG.md keeps the history, Libs/ is third party, the dated specs and plans
-- under docs/superpowers/ are records of what was, and this file has to name what it looks for.
-- It also checks the two renames a typo would break silently: the key binding's method and the
-- Loot Master's addon-message prefix.
--
--   luajit -e 'ADDON="."' tools/no-brutus.lua
--
-- Exits 1 on any failed check.
ADDON = ADDON or "."

local checks, fails = 0, {}
local function check(cond, what)
  checks = checks + 1
  if not cond then fails[#fails + 1] = what end
end
local function read(rel)
  local f = io.open(ADDON .. "/" .. rel, "rb")
  if not f then return nil end
  local s = f:read("*a")
  f:close()
  return s
end
local function excepted(rel)
  return rel == "CHANGELOG.md" or rel == "tools/no-brutus.lua" or rel:find("^Libs/")
      or rel:find("^docs/superpowers/specs/") or rel:find("^docs/superpowers/plans/")
end

local files = {}
local p = io.popen('git -C "' .. ADDON .. '" ls-files')
for line in p:lines() do files[#files + 1] = line end
p:close()
check(#files > 100, "git lists the addon's files (" .. #files .. ")")

local hits = {}
for _, rel in ipairs(files) do
  if not excepted(rel) then
    local s = read(rel)
    if s and s:lower():find("brutus", 1, true) then hits[#hits + 1] = rel end
  end
end
check(#hits == 0, ("no tracked file names BRutus (%d do: %s%s)"):format(#hits,
  table.concat(hits, ", ", 1, math.min(#hits, 12)), #hits > 12 and ", …" or ""))

-- The key binding calls a method that exists.
local bindings = read("Bindings.xml") or ""
local method = bindings:match("GuildOS:(%w+)%(")
local defined = false
for _, rel in ipairs(files) do
  if method and rel:find("%.lua$") and not excepted(rel) then
    local s = read(rel)
    if s and s:find("function GuildOS:" .. method .. "(", 1, true) then defined = true end
  end
end
check(method and defined, "Bindings.xml calls GuildOS:" .. tostring(method) .. "(), which is defined")

-- The Loot Master's prefix is one constant, the same everywhere, and the client takes it.
local lm = read("Modules/LootMaster.lua") or ""
local prefix = lm:match('LootMaster%.PREFIX%s*=%s*"([^"]+)"')
check(prefix == "GuildOSLM", "LootMaster.PREFIX is \"GuildOSLM\" (got " .. tostring(prefix) .. ")")
check(prefix and #prefix <= 16, "and fits the client's 16-byte prefix limit")
local _, literals = lm:gsub('"GuildOSLM"', "")
check(literals == 1, "the prefix is written once, as the constant, and every use reads it (" .. literals .. " literals)")

if #fails > 0 then
  for _, f in ipairs(fails) do io.stderr:write("FAIL: " .. f .. "\n") end
  os.exit(1)
end
print(("no-brutus: %d checks passed"):format(checks))
```

- [ ] **Step 1: Write the rename script**

```python
# rename_brutus.py — run from the addon root. Replaces the substring BRutus with GuildOS in every
# tracked text file outside the guard's exceptions, keeping each file's line endings byte for byte.
import subprocess, re
EXCEPT = re.compile(r"^(CHANGELOG\.md|tools/no-brutus\.lua|Libs/|docs/superpowers/(specs|plans)/)")
BINARY = re.compile(r"\.(tga|blp|ttf|otf|png|jpg|ogg|mp3|zip)$", re.I)
files = subprocess.run(["git", "ls-files"], capture_output=True, text=True, check=True).stdout.split("\n")
changed = 0
for rel in filter(None, files):
    if EXCEPT.search(rel) or BINARY.search(rel):
        continue
    raw = open(rel, "rb").read()
    if b"BRutus" not in raw:
        continue
    open(rel, "wb").write(raw.replace(b"BRutus", b"GuildOS"))
    changed += 1
print("files changed:", changed)
```
