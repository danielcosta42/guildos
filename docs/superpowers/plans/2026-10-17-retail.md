# Retail: the third client — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GuildOS loads and is useful on retail WoW (Midnight 12.1.5, interface 120105), with loot and the
site absent there, and Forever and Anniversary unchanged.

**Architecture:** `GuildOS.Client` gains `isRetail`/`game` and per-game fields (classes, enchant slots);
retail-absent modules return before defining their global (ADR-0014's pattern); member keys on retail keep
each member's own normalized realm. One TOC carries the three interfaces, added last.

**Tech Stack:** Lua 5.1 (WoW), LuaJIT harnesses in `tools/`, luacheck, Python 3 for the catalog generator,
GitHub Actions + BigWigs packager. guildos-web: TypeScript, vitest.

**Spec:** `docs/superpowers/specs/2026-10-17-retail-design.md`

## Global Constraints

- Retail interface: `120105` (build 12.1.5.70448). TOC line: `## Interface: 20506, 16001, 120105`.
- `isRetail` = `WOW_PROJECT_MAINLINE ~= nil and WOW_PROJECT_ID == WOW_PROJECT_MAINLINE and interface >= 100000`.
- Unknown client stays Forever. `isAnniversary` keeps its name and meaning; a harness stub without `isRetail` reads as Forever.
- Retail level cap 90; raid sizes `{10, 20, 30}`, default 20; tracked difficulties 14, 15, 16.
- Retail enchant slots: 1, 3, 5, 8, 11, 12, 16. Others keep 1, 3, 5, 7, 8, 9, 10, 15, 16.
- Retail classes: the 9 classic + DEATHKNIGHT, DEMONHUNTER, MONK, EVOKER (13).
- Absent on retail: LootMaster, LootTracker, LootEquity, Points, SoftRes, Wishlist, Companion (CompanionExport), CompanionImport, Look; features `loot`, `dkp`, `wishlist`, `web`, `lootTracker`, `lootMaster`.
- Version-sensitive API calls only in `Core/Compat.lua` (compat-guard enforces it).
- Every check: `luacheck . --config .luacheckrc` (one known warning, Inbox.lua:5), `luajit tools/compat-guard.lua`, every `luajit -e 'ADDON="."' tools/<harness>.lua`, `python tools/prof_catalog.py`, `python tools/beta-workflow.py`.
- Commits: Conventional Commits in Portuguese, ending with the issue number; no AI attribution.
- PRs stacked, none merged before the maintainer's in-game review.

## Review Focus

1. **A realm with a space or a hyphen** ("Tol Barad", "Azjol-Nerub"): a key built from `GetRealmName()` and one from the roster line must be the same key — test in Task 2.
2. **My own record on retail**: `PlayerName()` + client realm must equal the roster's key for me, or I show as a second member without the addon — test in Task 2.
3. **Slash verbs of absent features on retail** (`/gos dkp`, `/gos web`, `/gos roster`, `/gos lm`, `/gos wishlist`, `/gos softres`, `/gos equity`) must print and not raise — test in Task 3.
4. **A secret `encounterName`** in `ENCOUNTER_END` must not raise — test in Task 3.
5. **Members of two connected realms with the same name** ("Ana-Azralon", "Ana-Gallywix") stay two records through start-up — test in Task 2.
